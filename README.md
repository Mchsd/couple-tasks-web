# 情侣每日约定 · 使用说明

> 双人共享任务表 | 数据私有 | 已在 GitHub 上线 ✅ (2026-08-19)

## 🚀 打开方式

**页面（公开空壳）**：https://mchsd.github.io/couple-tasks-web/

**数据（私有）**：`Mchsd/couple-tasks` 仓库的 `data.json` —— 只有你们两人的 token 能读写

## 🔑 首次使用（每台设备只需一次）

1. 打开页面 https://mchsd.github.io/couple-tasks-web/
2. 点底部 **⚙️ 设置名字**
3. 填入：
   - 两个名字（各自称呼）
   - **GitHub 同步令牌**：细粒度 PAT（仅 `couple-tasks` 仓库 Contents 读写）
4. 保存 → 底部显示 **"☁️ 已云端同步"** 即成功

> 两人共用一个 token 即可（或各自生成一个，权限相同）。token 只存在自己设备的 localStorage，不会上传到公开页面。

## ✅ 功能

- **🤍 情侣正字**（正字系统集成）：完成约定 → 共同攒一画；5 画 = 1 个「正」字 = 🎁 小惊喜；25 画 = 🎉 大惊喜 + 🤍 爱 +1。5 个正字格逐笔点亮（发光动画），完成格有心跳标记；取消完成自动扣回一画
- **📅 完成日历**：GitHub 风格 17 周热力图（紫粉渐变 5 级色阶），点正字区块右上角 📅 查看
- **每日约定**：一方写下今日约定（可指定"谁定的"），双方可见
- **一起完成**：完成 + 记录谁完成的 + 时间 + 可留言（有快捷短语）
- **取消完成**：当天可反悔（正字同步扣回）
- **回忆墙**：过去所有约定留档（相对日期+完整日期）
- **双人统计**：各自设置数/完成数
- **连续天数**：🔥 连续完成徽章（7/30/100 天有庆祝彩蛋）
- **自动换新**：每天 0 点新任务
- **里程碑庆祝**：满 5 画彩带雨、满 25 画烟花 + 爱字

## 🔄 同步机制

- 读写 GitHub Contents API（`data.json`），带 sha 乐观锁防两人同时写冲突
- 无 token / 断网 → 自动降级本机 localStorage（显示"本机独立模式"）
- 页面每分钟自动刷新一次

## 🛠 技术结构

| 仓库 | 可见性 | 内容 |
|------|--------|------|
| `Mchsd/couple-tasks` | 🔒 私有 | data.json（全部数据） |
| `Mchsd/couple-tasks-web` | 🌐 公开 | index.html + manifest（空壳前端） |

## ⚠️ 注意

- **token 权限已最小化**：只能读写 couple-tasks 的 Contents，无法访问其他仓库/删除仓库
- 若两人同时修改（一方还没刷新），后写的一方会触发冲突自动重试，最终以最后一次写为准
- 泄露 token 的风险：仅限能访问你们数据仓库内容的人——token 本身只有 contents 权限，危害有限
